# Golang Talks

A collection of presentations and sample code about Go (Golang), presented by Chee Leong ([@klrkdekira](https://github.com/klrkdekira)) at Golang Meetup Kuala Lumpur.

## View Locally

```bash
go tool present
```

Open [http://localhost:3999](http://localhost:3999) to view the slides.
